# Zikirmatik — bağımsız uygulama

Bu proje, Vaktuna reposundan **ayrı** çalışan, ücretsiz ve kurulabilir bir mobil web uygulamasıdır (PWA). Vaktuna kaynak koduna dokunulmamıştır.

## Özellikler

9 hazır zikir, özel zikirler, titreşim destekli sayaç, geri alma, sıfırlama, 33/34/100/özel hedef, günlük toplam ve son 30 gün geçmişi, açık/koyu/sistem görünümü, Türkçe/İngilizce arayüz, tarayıcıda yerel kayıt, çevrimdışı kullanım. Hızlı çift dokunma yakınlaştırması ve yatay kayma engellenir.

## Yayınlama

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root). Yayınlandığında iPhone Safari → Paylaş → Ana Ekrana Ekle yoluyla kurulur. GitHub Pages özel veri depolamaz; tüm sayımlar cihazdaki localStorage içinde kalır.

## Kaynak hakkında

Vaktuna'nın Zikirmatik modülündeki veri ve sayım mantığı esas alınarak **bağımsız bir uygulama olarak yeniden uygulanmıştır**. Bu, Vaktuna projesinin tüm dil çevirilerinin veya birebir kaynak kodunun aktarılması değildir. Vaktuna'nın orijinal uygulaması aynen korunmuştur.
